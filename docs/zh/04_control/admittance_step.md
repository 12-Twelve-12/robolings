# admittance_step：导纳控制单步

文件：`exercises/04_control/admittance_step.py`

要实现：`admittance_step(x, v, x_ref, f_ext, M, D, K, dt)`

## 题目

导纳控制的一步：实测的力推动一个虚拟质量。

阻抗控制（`mit_torque`）把位置误差变成力矩。导纳控制是反方向：实测的接触力 `f_ext` 驱动一个虚拟的质量-弹簧-阻尼系统，算出来的位置才是下发的指令。弹簧锚在 `x_ref` 上：

```
M * a + D * v + K * (x - x_ref) = f_ext
```

解出 `a`，再用半隐式欧拉积分，这是弹簧很硬时仍然稳定的那种：

```
v_new = v + a * dt
x_new = x + v_new * dt
```

注意 `x_new` 用的是**新的**速度。显式写法用旧的 `v`，每一步都会凭空多出能量。

`x`、`v`、`x_ref`、`f_ext`、`M`、`D`、`K` 都是浮点数，或者形状相同的数组（每个轴一个）。`dt` 是浮点数。

返回 `(x_new, v_new)`，形状和 `x` 相同。

## 约定

夹在策略和电机之间的小函数。它们都很简单，而把其中任何一个弄得有一点点不对，都是损坏硬件的常见方式。
