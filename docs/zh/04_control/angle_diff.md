# angle_diff：角度回绕与最短角度差

文件：`exercises/04_control/angle_diff.py`

要实现：`wrap_to_pi(a)` 和 `angle_diff(a, b)`

## 题目

这道题有两个函数。

### wrap_to_pi

把弧度制的角度回绕到 `-pi` 到 `pi` 之间。

`a` 是标量或数组，可能离零点好多圈。

恰好半圈时，返回 `-pi` 或 `pi` 都可以。

返回和 `a` 形状相同的数组。

### angle_diff

求从角度 `b` 转到角度 `a` 的最短有符号转角。

对连续旋转的关节或者航向角来说，直接用 `a - b` 当误差是错的：从 179 度到 -179 度只差 2 度，不是 -358 度。控制器拿到原始差值，就会让关节绕远路转过去。

结果是把 `a - b` 回绕到 `-pi` 到 `pi` 之间。

返回 `a` 和 `b` 广播后形状的数组。
