# force_closure：抓取的力封闭判定

文件：`exercises/03_hand/force_closure.py`

要实现：`is_force_closure(contacts, normals, mu)`

## 题目

判断平面上的两指抓取能不能抵抗任意外力旋量。

两个带摩擦的点接触能夹住物体，当且仅当两点的连线同时落在两个摩擦锥内。这时两根手指可以沿着这条线对夹，而两端各自可用的摩擦，足以覆盖物体本来可能滑走的所有方向。

记 `d` 为从接触点 0 指向接触点 1 的单位向量。抓取要求接触点 0 处的力沿 `+d`、接触点 1 处的力沿 `-d`，并且各自都在自己那个半角为 `arctan(mu)` 的锥内。

判据要比分量，不要比角度。把一个方向 `u` 按单位法向 `n` 拆开，和 `friction_cone` 里的做法一样：

```
along  = dot(u, n)
across = norm(u - along * n)
```

当 `along > 0` 且 `across <= mu * along` 时，这个方向就在锥内。它和 `angle(u, n) <= arctan(mu)` 是同一个判据，但 `arccos` 在 1 附近会把 1e-16 的舍入误差放大成 1e-8，把一个完全站得住的斜向抓取判成打滑。

只检查两个法向是不是相对着，是不够的。任何一对对顶接触都能通过那种检查，而法向一旦偏离连线，`mu` 稍小就会滑。

- `contacts`：`(2, 2)`，平面上的两个接触点。
- `normals`：`(2, 2)`，每个接触点处指向物体内部的法向，不必是单位长度。
- `mu >= 0`，摩擦系数。

返回 Python 的 `bool`。
