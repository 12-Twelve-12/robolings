# voxel_downsample：体素下采样

文件：`exercises/08_perception/voxel_downsample.py`

要实现：`voxel_downsample(points, size)`

## 题目

把点云稀释成每个被占用的体素只留一个点。

把空间切成边长 `size`、与坐标轴对齐的立方体，下标 `(0, 0, 0)` 的那个从原点开始：

```
index = floor(p / size)
```

每个被占用的立方体贡献一个输出点：落进它的那些点的质心。不是立方体的中心，也不是最先进来的那个点。

输出按体素下标排序，对 `(ix, iy, iz)` 做字典序，这样结果不依赖输入顺序。

留意负半轴：`floor(-0.1)` 是 `-1`，所以 `-0.1` 和 `0.1` 在不同的体素里。朝零截断会把它们放进同一个。

`points` 是 `(N, 3)`，`size > 0`。返回 `(M, 3)`，`M <= N`。

## 约定

相机坐标系：`z` 朝前穿过镜头，`x` 朝右，`y` 朝下。像素 `u` 沿列方向，`v` 沿行方向。
