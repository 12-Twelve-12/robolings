# fit_plane：最小二乘平面拟合

文件：`exercises/08_perception/fit_plane.py`

要实现：`fit_plane(points)`

## 题目

穿过点云的最小二乘平面，写成 `dot(n, p) + d = 0`。

策略把东西放上去的那张桌子就是这么找到的。把点减去均值，对去中心后的 `(N, 3)` 矩阵做 SVD，法向就是**最小**奇异值对应的右奇异向量：点云在这个方向上最薄。然后对质心 `c` 取 `d = -dot(n, c)`。

`n` 的符号是自由的，所以把它定下来：选让 `d >= 0` 的那个符号，这样 `n` 指向原点所在的那一侧。（平面穿过原点时 `d = 0`，两个符号都接受。）

`points` 是 `(N, 3)`，`N >= 3`。

返回 `(n, d)`：单位长度的 `(3,)` 数组和一个 Python `float`。

## 约定

相机坐标系：`z` 朝前穿过镜头，`x` 朝右，`y` 朝下。像素 `u` 沿列方向，`v` 沿行方向。
