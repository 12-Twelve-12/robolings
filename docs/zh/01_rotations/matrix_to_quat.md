# matrix_to_quat：旋转矩阵转四元数（数值稳定）

文件：`exercises/01_rotations/matrix_to_quat.py`

要实现：`matrix_to_quat(R)`

## 题目

求旋转矩阵对应的单位四元数 `[w, x, y, z]`，要求 `w >= 0`。

教科书上的做法是先算 `w = sqrt(1 + trace) / 2`，再除以 `w` 得到向量部分。转角接近 180 度时 `w` 接近零，这个除法会出问题。正确做法是按 `trace`、`R[0,0]`、`R[1,1]`、`R[2,2]` 中最大的那个分情况处理，保证除数始终不小。

`q` 和 `-q` 表示同一个旋转，返回 `w >= 0` 的那个。

返回 `(4,)` 数组。

## 约定

- 旋转矩阵是 3x3，作用在列向量上，把本体系坐标变到世界系。
- 四元数顺序是 `[w, x, y, z]`（标量在前），Hamilton 约定。
- 全部用 `float64`。
