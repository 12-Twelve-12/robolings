# slerp：球面线性插值

文件：`exercises/01_rotations/slerp.py`

要实现：`slerp(q0, q1, t)`

## 题目

在两个单位四元数之间做球面线性插值。

`t = 0` 得到 `q0`，`t = 1` 得到 `q1`（允许差一个符号）。

有两个细节在真机上很要紧：

- `q1` 和 `-q1` 是同一个姿态。如果 `dot(q0, q1) < 0`，要把 `q1` 取反，让插值走近路。
- 两个四元数几乎相同时，`sin(theta)` 接近零。当 `dot > 0.9995` 时改用归一化的线性插值。

返回单位长度的 `(4,)` 数组。

## 约定

- 旋转矩阵是 3x3，作用在列向量上，把本体系坐标变到世界系。
- 四元数顺序是 `[w, x, y, z]`（标量在前），Hamilton 约定。
- 全部用 `float64`。
