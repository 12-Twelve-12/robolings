# kabsch：两组点之间的最优旋转

文件：`exercises/01_rotations/kabsch.py`

要实现：`kabsch(P, Q)`

## 题目

求把点集 `P` 对齐到点集 `Q` 的最优刚体变换，也就是让下式最小的旋转 `R` 和平移 `t`：

```
sum_i || R @ P[i] + t - Q[i] ||^2
```

把动捕坐标系对齐到机器人坐标系、把两个传感器看到的同一块标定板配准起来，用的都是它。

Kabsch 算法：

1. 两组点各自减去质心。
2. `H = P_centered.T @ Q_centered`
3. `U, S, Vt = svd(H)`
4. `d = sign(det(Vt.T @ U.T))`
5. `R = Vt.T @ diag(1, 1, d) @ U.T`
6. `t = centroid_Q - R @ centroid_P`

最容易漏掉的是第 4 步。漏了它，数据有噪声或者点几乎共面时，可能得到一个镜像：这个矩阵是正交的，对点的拟合也不错，但行列式是 -1，不是旋转。

`P` 和 `Q` 是 `(N, 3)`，行与行一一对应。

返回 `(R, t)`，形状分别是 `(3, 3)` 和 `(3,)`。

## 约定

- 旋转矩阵是 3x3，作用在列向量上，把本体系坐标变到世界系。
- 四元数顺序是 `[w, x, y, z]`（标量在前），Hamilton 约定。
- 全部用 `float64`。
