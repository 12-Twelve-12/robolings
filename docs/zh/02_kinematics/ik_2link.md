# ik_2link：两连杆解析逆解

文件：`exercises/02_kinematics/ik_2link.py`

要实现：`ik_2link(x, y, l1, l2)`

## 题目

求平面两连杆机械臂的两个闭式解。

`dls_ik_step` 之所以要迭代，是因为一般的串联链没有公式可用。平面两连杆有，把它放在这里，是为了说明迭代是退路，而不是起点。

记 `r2 = x**2 + y**2`，余弦定理给出肘关节角：

```
cos(q2) = (r2 - l1**2 - l2**2) / (2 * l1 * l2)
```

肩关节角随之而来：

```
q1 = arctan2(y, x) - arctan2(l2 * sin(q2), l1 + l2 * cos(q2))
```

每个可达点都有两个解，一个 `q2 >= 0`、一个 `q2 <= 0`，它们在工作空间边界上重合。

目标不可达，就是 `cos(q2)` 跑出 `[-1, 1]` 的时候：`r > l1 + l2` 是太远，`r < abs(l1 - l2)` 是落进了中间那个洞里。两种情况由同一个判断覆盖，这也是值得这样写、而不是去比半径的原因。

返回 `(2, 2)` 数组，第 0 行 `q2 >= 0`、第 1 行 `q2 <= 0`，每行是 `[q1, q2]`。目标不可达时返回 `None`。
