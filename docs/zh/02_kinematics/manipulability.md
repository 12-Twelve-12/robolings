# manipulability：可操作度

文件：`exercises/02_kinematics/manipulability.py`

要实现：`manipulability(J)`

## 题目

计算 Yoshikawa 可操作度。

用一个数刻画末端在最差方向上还能产生多少速度：

```
w = sqrt(det(J @ J.T))
```

它是单位关节速度映射成的那个椭球的体积，在奇异位形处恰好为零。这正是它作为预警指标的价值：`dls_ik_step` 里的阻尼项，存在的理由就是要熬过这个指标正在提示你的那些位形。

照字面去算会把条件数平方。把 `J` 的奇异值乘起来是同一个答案，而且保留更多有效位：

```
w = prod(svdvals(J))
```

注意 `det(J)` 不能拿来顶替：它只对方阵有定义，而冗余臂的关键之处恰恰在于 `J` 不是方的。`J.T @ J` 也不能和 `J @ J.T` 互换：关节数多于任务维数时，前者是奇异的，行列式处处为零。

`J` 是 `(m, n)`。当 `m > n`，任务维数比关节数还多，此时测度为 0。

返回 Python 的 `float`。
