# ekf_predict：EKF 预测步

文件：`exercises/09_state_estimation/ekf_predict.py`

要实现：`ekf_predict(x, P, f, F, Q)`

## 题目

扩展卡尔曼滤波的预测那一半。

状态过运动模型，协方差过它的雅可比：

```
x_pred = f(x)
P_pred = F @ P @ F.T + Q
```

`f` 是 Python 可调用对象，`f(x)` 返回下一个状态 `(n,)`。`F` 是它在 `x` 处的 `(n, n)` 雅可比，已经算好了。`Q` 是 `(n, n)` 的过程噪声。

协方差在这里只会变大，只有更新步才让它变小。不要原地改 `P`：调用方可能还拿着它。

返回 `(x_pred, P_pred)`。

## 约定

机器人从来看不到自己的状态，它看到的是传感器。陀螺仪平滑但会漂，加速度计吵但不漂，卡尔曼滤波则是把预测和测量加权起来的通用办法。这条专题把这些零件一个一个搭起来。
